# Client scheduled callback visibility

- Added role-scoped pending scheduled callbacks to the dashboard API.
- Client users now see scheduled callbacks only for orders that belong to their own client account.
- Employee users see callbacks assigned to them.
- The dashboard includes a Scheduled Calls / Rappels planifiés / المكالمات المجدولة card with order, customer, phone, assigned employee, date/time, notes and overdue state.
- When a callback is scheduled, the client account now receives a callback_scheduled notification in addition to the employee notification.
