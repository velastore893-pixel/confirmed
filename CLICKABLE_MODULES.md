# Clickable workspace modules

The dashboard workspace tiles are real Next.js links. Clicking anywhere on a tile opens its corresponding route.

Examples:
- Orders -> `/orders`
- Stores -> `/stores`
- Invoices -> `/invoices`
- Reports -> `/reports`
- Employees -> `/employees` (admin)
- Clients -> `/clients` (admin)
- Delivery -> `/delivery` (admin)
- Distribution -> `/distribution` (admin)
- Finance -> `/finance` (admin)
- Notifications -> `/notifications`
- Activity -> `/activity` (admin)
- Settings -> `/settings` (admin)

The desktop app launcher, mobile menu and mobile bottom navigation also use real routes.
