# CODFlow Premium UI Redesign

This pass upgrades the complete application shell and shared design system without removing backend functionality.

## What changed
- Premium light SaaS visual system matching the approved concept.
- Cleaner centered desktop shell with a compact app launcher instead of a permanent sidebar.
- Functional mobile bottom navigation linked to real routes.
- Role-aware account menu: admin-only Settings no longer appears for roles that cannot access it.
- Refined typography, cards, KPI blocks, tables, badges, forms, modals, empty states and integration cards.
- Dashboard spacing, date selector, module launcher, analytics and employee cards aligned to the approved mockup direction.
- Mobile layouts receive touch-friendly controls and reserved spacing for navigation.
- Added keyboard focus styles for accessible navigation.

## Functionality preserved
Existing API calls, order confirmation actions, store connections, SIFT integration, Google Sheets sync, billing, role checks and route links are preserved. Visual controls added in this pass are real links/actions; no decorative fake buttons were added.
